    How it works

    1. Make the style key first, in the World Builder. Every object is matched to it, as the ground is.
    2. Open a group below. Most objects come on sheet pictures: one ChatGPT picture of many objects in tidy rows. Copy a sheet's prompt into a new ChatGPT chat, and attach the style key, and only the key. Not your bro: the world is finer pixel art than he is, and ChatGPT copies what it sees.
    3. Bring the picture back with Add sheet picture. The page cuts out every object, names each one by its place on the sheet (check the names under each, and tap to change one), makes each exactly its size in the game, and gives it its own 64 colours with hard pixel edges.
    4. Every object also has its own prompt, to make or redo just that one: a picture made with it wins over the sheet's. The buildings are one to a picture: each needs its detail.
    5. See it at game size: it stands on its land's ground next to your bro, as big as it will be on your phone.
    6. Not right? Ask the same chat again, or start a fresh one, and Replace it. The size can be nudged too.
    7. When you are happy, Download for the game and upload it to GitHub (at the bottom). Only objects with a finished picture go in it, so check every card has one. The game puts each object in its place in the Wheel itself.

    Save and send

    Download all is your backup: every picture as ChatGPT made it, every object as the game will use it, and your size choices. Keep it in iCloud or Google Drive, not on GitHub. Restore brings everything back on any device.

    Download for the game is what goes on GitHub: the finished objects packed a few to a sprite sheet (each building a sheet of its own), every sheet a small picture of 255 colours or fewer, with a list of where each one is, in zips of under 25 MB so GitHub's website takes each one. The game loads only the sheets for the objects near you.

    Putting the objects in the game
    1. Tap Download for the game, then tap each Save part button that appears.
    2. On GitHub, open the repository, tap Add file → Upload files, choose every part, and commit them (any folder is fine, for example art).
    3. Tell Claude the objects are uploaded. A session unpacks them into the game and checks them.
