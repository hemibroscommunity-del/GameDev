Put BroTown's hiscores on Hemi

Four taps, two copy-pastes, about five minutes. Open this page inside your wallet's browser (MetaMask app → the browser tab) so it can ask your wallet to sign.

Step 1

Connect your wallet

Your connected account becomes the guardian — the one address that can ever replace the game's signing key. It also pays the two transactions (well under a dollar total). The page will switch your wallet to the Hemi network, adding it first if it's new.

Step 2

Create the game's signing key

Generated on this device, right now — it never leaves this page except when you copy it. The game's server uses it to sign score attestations.

Private key — copy it into Cloudflare now:

Cloudflare dashboard → Workers & Pages → brotown-server → Settings → Variables and Secrets → Add → name RELAYER_KEY, paste the key, type Secret, Save. Do this before you close this page. (If you ever lose the key after deploying, you're not stuck — the guardian can rotate to a new one.)
