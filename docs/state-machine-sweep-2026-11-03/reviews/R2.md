# R2 review · root cause and simplicity
- Overall: The plan is right about WHAT is broken. But in about half of its Wave 1 items it patches one instance and leaves the cause in place, and three of its fixes are wrong or moot as written.
  - Wrong:
    - W1.4's "refund: credit, then write" copies the raise path's order (storeoffer.js:156-163), and V8a showed that order MINTS gold: a restart between the credit and the write leaves a live offer with no gold behind it, and the seller's Yes then pays it out.
    - W1.9's movement freeze during the dungeon opening holds a blind player still while the Wheel's monsters keep hitting them, so V11's bag loss gets worse.
    - T1's proof window, 1366x768, passes today (264 / 0.35 = 754 < 768), so it cannot be the "fails first" test.
  - Moot:
    - W1.6's ten-file `ps.dying` sweep is not needed. The move can simply stop writing `ps.dead` (movement.js:796), because every worker write of `dead` already pairs with `dying`. That one line is also W2A's "dead is ignored".
    - W1.10's `SHIELD_CD_MS = 3000` edits dead code.
  - Small root fixes that replace a Wave 3 refactor:
    - the second-tab takeover runs the close's duties (v2.3.3174 already hand-patched one missing duty);
    - `connect()` detaches and closes the old socket itself;
    - the phone's duel flag is written only from the wire, cleared at state_sync, and re-sent by the worker;
    - a minimal `changeZone()`, plus a test that fails a bare zone write;
    - an inventory test over the monster's reset list;
    - the honest guard break shown from the stamina that every player_state already carries (no new field, cap or switch).
  - The waves:
    - W2A bundles five unrelated machines into one god-record. Most of it is Wave 1 one-liners, and the design that remains is one thing the plan does not name: the worker owns zone entry.
    - W2C is already house law (one write), needs no owner decision, and Wave 1's own server deploys open its crash windows, so it should move up.
    - Wave 3 should shrink to `_playerLeaves`, the veil's holder list and `switchCharacter()`. Guard tests cover the rest.
  - Also missing:
    - five cross-cutting causes, each now fixed one instance at a time;
    - no server deploys around the expo;
    - Wave 1 ordered by harm;
    - cheap honest-player fixes that no wave carries.
