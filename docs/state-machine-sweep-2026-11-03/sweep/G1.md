# G1 — client combat rules (monsterCombat.js, projectiles.js, combatHelpers.js, targeting.js)

Context that applies to every block below: in the live world (the Wheel) every monster list is the
worker's (`S._serverMonsters = true` on every Wheel zone_state, `mnear: 1`: wsClient.js:1805, 4329;
server/src/wheelnear.js:20-25), and NO variant sets `clientSideMovement` any more
(src/data/monsterVariants.js:672-676 + grep: no `clientSideMovement: true`), so the whole local-AI half of
monsterCombat.js (lines 202-1303) is dormant: it only runs on the retired old maps (`?trial=off`) or the
custom-dungeon fallback against an old worker (dungeonWaves.js:21-28). The player-side half (aim, lock,
swing, bow gate, projectiles) is LIVE.
