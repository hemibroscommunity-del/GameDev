## The rules for every PR

- **Nothing a player sees changes, and no writes.** A move changes no
  address's meaning: no default turned, no switch reaped, no row's form
  changed. No new switch is needed (the old switches stay as they are).
- **T's recipe.** `sw`/`swHas` for a single-name switch whose row needs
  nothing its old test lacks (every row here has `needs: []`), its old test
  kept word for word in `MOVED`. Else `pageAddress()`: a value, a lever with
  a number, a read of several names, or a site that hands the whole address
  to a rule. There only the `location.search` expression (with its
  `typeof` or `window` guard) becomes `pageAddress()`; the regex, the clamp
  and the rule stay word for word, and check 5 holds `pageAddress()`.
- **T2's own block in `MOVED`**: one comment line naming card T2 and the
  PR's tag, then that PR's lines, below the last entry. Each PR lowers
  `OUTSIDE_LINE` to check 3's new count and adds it to the line's comment.
- **Done when** (each PR): switch-reader check 1 holds each moved read;
  check 3 counts N fewer (N below) and its line says so; check 5 green;
  `node tools/guards/switches-thrown.test.mjs` green; `cd server && npm test`
  green; `questline` green.
- One branch a PR, each from the one before (all four change the guard);
  ready for review, not a draft; `docs/plan/status/T2.md` in each.
