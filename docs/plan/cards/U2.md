## Readings chosen for you

- "Covered" means a test GitHub runs fails the row's mistake. A check that
  runs only in precheck is not a gate (rule 1): it gets a guard.
- A covered row's break proof goes in the census file, not in its suite's
  header: a header edit under `server/test/` deploys the worker (TRAPS §277).
- Storage keys are strict from the start (rule 3). If `storage-keys` finds
  an unregistered key on `main`, write it under Found and ask: U2 changes
  nothing in `server/src/` and no registry row.
- `wheel-bakes` keeps under two seconds; if the check runs longer, ask
  before choosing another way (the plan's fingerprint, `planFingerprint`).
- A guard reads `src/ui/BroTown.jsx` and the two renderers by system
  (`readSystem('ui')`, `filesOf('render')`), never by line: cards M and M2
  are moving code in them. A break proof names a big file by name alone.
