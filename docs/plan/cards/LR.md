**Why (the owner, 2026-11-18):** the freezes cards HB and HB2 keep fixing (58 ms, 81 ms on a slow phone) mostly share one cause: code MEASURES THE PAGE at the wrong moment (`getBoundingClientRect`, `clientWidth`/`offsetWidth`/`clientHeight`, `innerWidth`, `getComputedStyle`/`getPropertyValue`, `elementFromPoint`, canvas `measureText` in a redraw loop, `querySelectorAll` in a timer) inside a React render/commit, a tap, or a frame, so the browser must stop and lay out the whole page then. See `docs/plan/census/HB-holds.md` (rows 3, 4, 5, 7, 10, 12, 13, 18, 21, 24, 32, 34, 36) and "By cause". The owner wants future work not to keep making them. This card adds a FAST check on every PR so a new one is refused when it is written.
