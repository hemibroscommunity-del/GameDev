# Single-element FX prompts

Two sheets per element, twenty in total.

**A - Special-attack burst.** The hit when your elemental special lands. One-shot, 8 frames.

**B - Status marker.** The lingering sign the element is still on the target, which is the
window you swap inside. Loops forever, 6 frames, small.

Copy a whole block. Do about six per sitting, in one conversation, so the style holds.


---

# A - Special-attack bursts (10)

### Flame special

```
Create a game visual-effect sprite sheet.

FORMAT (follow exactly):
- One image, 2048 x 256 pixels.
- A single horizontal row of 8 equal frames, each 256 x 256.
- Frames evenly spaced, no gaps, no borders, no numbers, no labels.
- Background: solid magenta #FF00FF across the whole image, including
  inside any enclosed loops of the effect.
- The effect is centred in each frame and stays inside its frame.

STYLE:
- Chunky 2D pixel art, bold shapes, high contrast, limited palette.
- Must read clearly when shrunk to 64 x 64 on a phone screen.
- No outline around the whole effect, no drop shadow, no ground plane,
  no character, no background scenery.

ANIMATION (left to right, one impact burst):
- Frame 1: small bright seed of the effect appearing.
- Frames 2-3: rapid expansion to full size, brightest here.
- Frames 4-5: full size, the shape at its most readable.
- Frames 6-8: dissipating and fading, smallest and dimmest at frame 8.
- Frame 8 leaves nothing behind.

THE EFFECT:
Flame elemental impact: a hard fireball impact — orange-red flame blooming outward with a white-hot core and ember flecks. Palette built from #C0392B.
```

# B - Status markers (10, looping)

### Burn — the Flame status

```
Create a game status-marker sprite sheet.

FORMAT (follow exactly):
- One image, 768 x 128 pixels.
- A single horizontal row of 6 equal frames, each 128 x 128.
- Frames evenly spaced, no gaps, no borders, no numbers, no labels.
- Background: solid magenta #FF00FF across the whole image, including
  inside any enclosed loops of the effect.
- The marker is centred in each frame and fills about half the frame.

STYLE:
- Chunky 2D pixel art, bold silhouette, high contrast, limited palette.
- This sits ON TOP of a monster and must stay readable at 24 x 24 pixels,
  so keep it to one clear shape - no fine detail, no thin lines.
- No outline around the whole marker, no drop shadow, no background.

ANIMATION - SEAMLESS LOOP (this is the important part):
- All 6 frames are the SAME size and brightness. This is not a burst.
- The motion is a gentle idle cycle that repeats forever.
- Frame 6 must flow straight back into frame 1 with no jump or pop.
- Nothing appears or disappears across the loop.

THE MARKER:
Burn: small flames licking upward, curling and re-forming. Palette built from #C0392B.
```
