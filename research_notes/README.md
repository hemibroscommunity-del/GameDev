# Research notes (v2.3.3078)

The working notes behind a research report. Each folder is one piece of
research; the finished report has the same name.

- `BroTown farming system design/`: how farming could work in BroTown
  (timed crops, digging, planting, watering and fertilizing, a private farm
  per player that friends can visit, the Land Office's starter plot and
  expansions, and what farming should give players). Three files cover what
  the game's code has today. Four cover how other games farm.

Nothing here changes the game. These are notes, and where they disagree
with the code, the code wins.
